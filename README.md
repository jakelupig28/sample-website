# ÉLAN Atelier & Sanctuary

A luxury haute coiffure, bespoke French balayage, and restorative Japanese trichology head spa web application crafted with Next.js, TypeScript, and modern kinetic motion design principles.

## Features
- **Editorial Hero**: Responsive split-layout with background image integration, moving pink and white silk gradient, and balanced typography.
- **Atelier Services in Motion**: Interactive 4-phase service choreography showcase featuring Kyle Zantos design motion principles, pulsing radar hotspots, and tactile micro-interactions.
- **Interactive Booking Flow**: Modal with real-time ritual selection, stylist matching, and calendar date reservation.
- **Lookbook & Portfolio**: Curated runway trends and portfolio gallery with high-resolution daylight photography.
- **Sanctuary Spaces & Master Artisans**: Architectural space specifications, sensory pairings, and master stylist credentials.
- **Atelier Location**: Official Google Maps embed with Greenwich Village navigation.

## Tech Stack
- **Framework**: Next.js (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules (Design Tokens, Responsive Grid, Fluid Motion)
- **Icons**: Lucide React
- **Animation**: Anime.js & CSS Hardware-Accelerated Transitions

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
